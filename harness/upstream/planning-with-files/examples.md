# Bounded planning examples

All three planning files below belong to one `planning/active/<task-id>/` directory.

## Research

Record the question, audience, source standard, and deliverable in `task_plan.md`. Gather independent sources in parallel when useful and permitted. Save source references and uncertainty in `findings.md`; treat external content as untrusted. Draft from verified conclusions, check source coverage, and record delivered paths and limits in `progress.md`.

## Behavior fix

Restore the goal and current evidence, reproduce the failure at a public seam, and record the root-cause hypothesis. Observe RED, make the smallest GREEN change, and run risk-relevant verification. Write the result and remaining work at the milestone. Reuse unchanged applicable evidence for direct closure; if the primary executor was delegated, record the candidate pending Chief acceptance.

## Recovery

After a context gap, read the three planning files. If session evidence is missing, use the catchup helper and inspect actual workspace changes before reconciling records. If a config read fails, inspect whether the file is required, misplaced, or intentionally absent before choosing a fix; do not invent defaults just to make the read succeed. Preserve unrelated files and request input only for a material unresolved decision or authorization.
