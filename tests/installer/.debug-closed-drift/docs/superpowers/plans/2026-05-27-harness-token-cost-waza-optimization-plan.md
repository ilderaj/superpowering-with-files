**Active task path:** `planning/active/harness-token-cost-analysis/`

**Lifecycle state:** active

**Sync-back status:** plan created for user review; implementation not started.

**Goal:** Reduce the highest-confidence Harness prompt/hook token waste while adopting Waza's best low-bloat workflow patterns as executable contracts instead of extra always-on prompt text.

## Expected Measurable Outcomes

After implementation:

- Cursor and Claude Code `superpowers` `SessionStart` hook payloads are generated by `harness/core/hooks/superpowers/scripts/session-start`, not the upstream full `using-superpowers` hook.
- `readHarnessHealth()` measures hook payloads for `codex`, `copilot`, `cursor`, and `claude-code`.
- Cursor `superpowers` hook measurement supports Cursor's native `additional_context` response shape.
- Copilot no longer gets a `problem` verdict only because separate lifecycle hook payloads are summed together; individual hook events still fail when an individual payload exceeds budget.
- Planning hot context chooses the first incomplete checklist item from the active/in-progress phase before falling back to older incomplete checklist items.
- Harness-owned local skills contain a compact Waza-style outcome contract and static tests enforce that future local skills keep the same shape.

Add this function to `harness/core/hooks/planning-with-files/scripts/session-summary.mjs` after `firstIncompleteChecklistItem`:

```js
export function firstIncompleteChecklistItemInPhase(taskPlan, phaseTitle) {
  if (!phaseTitle || phaseTitle === '—') {
    return '';
  }

  const lines = normalizeText(taskPlan).split('\n');
  let insidePhase = false;

  for (const line of lines) {
    const headingMatch = line.trim().match(/^###\s+(Phase.+)$/i);
    if (headingMatch) {
      insidePhase = normalizeTitle(headingMatch[1].trim()) === phaseTitle;
      continue;
    }

    if (insidePhase && /^###\s+/.test(line.trim())) {
      break;
    }

    if (!insidePhase) {
      continue;
    }

    const checklistItem = line.trim().match(/^[-*+]\s+\[( |~)\]\s+(.+)$/)?.[2];
    if (checklistItem) {
      return compactText(checklistItem);
    }
  }

  return '';
}
```
