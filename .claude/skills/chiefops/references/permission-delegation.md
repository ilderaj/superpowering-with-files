# ChiefOps Permission and Delegation Reference

Use only for permission, model/effort, subagent dispatch, or child-return
work. Binding authorization does not prove runtime enforcement; missing
enforcement fails closed. Child authority, permission, and allowed operations
are strict subsets of the parent envelope. Every child contract declares an
explicit model and thinking value and is mechanically narrower than its parent.

Validate one matching child return before parent acceptance; reject missing,
duplicate, unexpected, or drifted returns. These are manual contracts, not
native host enforcement.
