# Decision-control evaluation design

J04 implements a bounded offline contract. T1 is a 27-case contract replay with explicit comparable, answered, and abstention denominators. It retains the historical old-behaviour column only as `legacyReferenceAccuracy`; it is not an observed baseline. The runner applies only local equivalence mappings, preserves null as unevaluable, and rejects fixture-set drift.

T1.5 remains a protocol, not a result: freeze raw task inputs and visible evidence, remove answers/truth/outcomes, hash the rubric and methods, label blind, and retain reviewer conflicts as ambiguous. A Host model/effort/tool identity that cannot be authenticated is unknown and cannot support a matched accuracy claim.

The all-in T2 profile sums every measured event per arm. `totalTokens` is input plus output and `freshTokens` subtracts cached input. Missing usage, unattributed overhead, zero denominators, and absent holdout evidence produce `unproven`. The +5% total-token band is covered only by preregistered efficiency improvement reproduced across two rounds and independent holdout. No live experiment is started by J04.


## J04 scoped remediation metadata (2026-09-22)

The accuracy runner owns an independent truth vocabulary, including `unsupported`; unsupported labels remain in `correctOverAll` and are excluded only from abstention. Risk reports expose eligible, evaluated, numerator, denominator, and evaluated coverage separately. Premature execution eligibility includes intake cases requiring `plan` and plan bundle cases whose readiness truth is `replan`. Shadow `null` recommendations are unevaluable and never disagreements. These are offline contract metrics only; they do not establish live model accuracy or production behavior.


## T1.5 and T2 execution order

The detailed freeze remains [audit S4](jev-swf-audit-20260920/spec.md#s4-可复算的评估a04a05a08a09j04). Chief labels raw decision-time inputs, then two independent reviewers adjudicate before predictions. Use24 real cases (12coding/12office) plus6 synthetic boundaries; development/holdout are task-group disjoint. Synthetic regression cases do not establish live accuracy. A30-case pilot may be inconclusive; do not keep retuning against the same holdout. Preserve ambiguous labels separately.

Before T2: accepted remediation and actual WP07 call, independent T1.5 screening, available real usage/events, frozen method/model/rubric and separately bounded intervention authorization. WP07 shadow is not an intervention. Two rounds and independent holdout are acceptance criteria, not a reason to require results before starting the experiment. Paired McNemar is used for comparative T1.5 correctness; profile bootstrap intervals summarize efficiency uncertainty and are not a substitute for a power calculation.

The current profile requires all attributable overhead INCLUDED (not symmetrically excluded), task-disjoint holdout, preregistration before events, observed output tokens, no primary metric regression, and measured effects rather than boolean declarations of improvement. Missing proof yields unproven. Supported/unchanged/regressed/inconclusive are valid findings; no requirement to manufacture gains. No live experiment has run.
