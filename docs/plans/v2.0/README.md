## 固定决定

- 在既有 eval 目录增加一个无依赖、离线、显式输入的纯计算报告工具。复用 token-audit 的术语和来源线索，不直接把其会话总量当实验任务增量，不重构旧 CLI。
- 不扫全局 sessions，不监听，不自动采集、不创建模型调用器、不建立用量数据库。Host 轨迹按明确实验窗口人工绑定，纯函数校验和计算。
- 把方法收益实验与模型/协作策略实验分开。方法实验固定同一模型、effort、工具和拓扑；策略实验允许模型/拓扑变化但独立成组，计入主任务、子任务和交接成本。
- 第一版只输出报告与采用/不采用/退役建议；不改默认模型，不加自动升级，不改 Root 路由。用户指定模型始终优先。
- 20-D 固定为已有 Codex Host 上的一个新工作区试点，不开发新 Host adapter。没有具体需要时 Chief 记录停止理由；不影响最小发布。
- DSH 完全不在实施、测试、分发和试点范围。保持六项治理逻辑清单（entry + 五技能），不增加角色或第四任务状态。

主执行者每次仅持有一个切片。C1 的来源盘点可与 A2 并行，但采用结论等待 B1。无调用能力时保留对应回放未执行，不自行换 Astra。请求型号是意图；实际型号需要 Host 证据。

最小交付是可复算报告、两轮完整比较、明确采用/不采用决定及可回滚的方法说明。经济收益未证明时可接受如实报告，**不能宣布省 token 或扩大默认采用**。质量/边界失败必须保留；修复后用新的预登记 cohort 重跑，不覆盖旧结果。没有真实回放时只到代码候选，不是 V2.0 正式验收。

本计划的实施与正式验收已完成；发布、提交与 adoption 仍按后续授权和仓库保护规则执行，不以 direct push 绕过 PR/CI。
