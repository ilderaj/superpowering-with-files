# DS Flash / Luna 子代理选择与交接

依据：2026-09-09 本地 V2 对照实验，证据位于 `.harness/verification/v2.0/ds-luna-20260909/`。这是小样本合成任务的操作建议，不是模型能力排名或价格结论。

两条已验证请求配置为 `opencode-go/deepseek-v4-flash` + `high`、`main/gpt-5.6-luna` + `high`。实际执行仍以 Host 记录为准。quota 紧张时可选另一条；本实验不证明它们具有独立额度，不使用 reset，也不改变默认模型。

| 工作 | 使用建议 | 必需验证 |
|---|---|---|
| 明确规则的抽取、模板补齐 | 两者均可，优先当前可用通道 | 明确 JSON 类型、未知值、时间优先级；逐条核对事实 |
| 小范围代码修复 | 两者均可 | 可观察 RED/GREEN；独立行为测试，包括重复值与边界 |
| 缺陷审查 | 两者均可作候选 reviewer | Chief 核查遗漏、误报与证据；不能由产出方自验收 |
| Office 综合输出与增量更新 | 两者均可产候选，不自动验收 | 人工填写栏目、状态更新、未知保留、事实与建议分离 |
| 换模型续做 | 从冻结文件 checkpoint 新开原生 worker | 源文件 hash、源/目标 Host 模型证据、增量范围、旧状态清除 |

交接包只需任务三文件绑定、输入/产物路径与 hash、已完成/剩余工作、允许写入范围、验证命令及停止条件。保持现有 Trio 和 native-first 范式；不恢复 visible worker 契约，不添加模型注册表或调度框架。不要把完整旧对话复制进每个 worker。

多个独立小检查可组成有界任务包以摊薄启动开销，要求同权限与清晰输出目录。共享上下文意味着样本不独立、费用只能计到包；有因果依赖或跨写入权限的任务不强行合并。批量读取与本地校验，最终返回路径、退出码、问题摘要；Chief 只在具体问题时读取完整轨迹。

成本至少分开记录未缓存输入、缓存输入、输出、响应次数、耗时、修复和 Chief 开销。缺少价格/账单时保留 unknown。跨提供商 token 不直接比较货币或 quota。`response_id` 为空时按原始记录位置保留，再与 Host 累计计数对账；不能按空 ID 去重。总调度消耗不冒充纯审阅消耗。

本次验证的是已生成文件加新增需求的交接，不是工具调用途中断、Host 崩溃或实际 quota 耗尽后的恢复。此边界不影响上述文件交接用法，但不能扩展验收声明。
